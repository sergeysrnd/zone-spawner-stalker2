# Изменения

## 0.4.0-preview — 2026-10-14

Первый публичный пакет для проверенной Steam build 25382007 / UE 5.5.4.

- Каталог, поиск, количество 1–999, избранное и независимые сортировки категорий.
- Редкость и базовые свойства артефактов, совместимость обвесов.
- Калибр оружия, совместимость боеприпасов с учётом уникальных моделей и типа пули.
- Чтение реального рюкзака по запросу, «Добавить такие же», +30/+60/+100 патронов.
- Сохранённые телепорты, возврат, координаты видимых целей заданий КПК и запрет неизвестной Z.
- Каталог NPC/мутантов, ограничение количества, дистанция и ранг.
- Запуск/закрытие меню вместе с игрой; горячая клавиша Ctrl + Alt + S.
- Убран постоянный вызов игрового потока в простое; чтения разбиты на отменяемые порции.
- Публичные инструкции, скриншоты, тесты и локальный импорт описаний вместо распространения полного текста игры.
