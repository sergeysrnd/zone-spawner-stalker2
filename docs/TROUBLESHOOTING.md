# Неполадки

| Симптом | Что проверить |
| --- | --- |
| Ctrl + Alt + S не открывает меню | Игра/меню должны быть запущены. Посмотри значок Zone Spawner в трее; после «Завершить» запусти EXE вручную. При конфликте клавиши используй трей. |
| «Ожидание игры» | Загрузи сохранение; проверь точную версию UE4SS/фикса и папку установки. После изменения Lua нужен перезапуск игры. |
| Установщик сообщает об изменённой сборке | SHA-256 EXE не совпал с проверенной сборкой. Нужна новая проверка совместимости; текущий пакет автоматически её не обещает. |
| Уже есть `dwmapi.dll` / `ue4ss` | Установщик сохраняет существующий загрузчик. Проверь его происхождение и другие моды перед чистой установкой. |
| Steam не найден | Нажми «Выбрать папку» и укажи корень игры. Пустая запись библиотеки без EXE не считается установленной копией. |
| Фикс не найден после Nexus | Дождись окончания скачивания V1.2, нажми «Найти скачанный ZIP» или «Выбрать ZIP». При нестандартной папке скачивания используй ручной выбор. |
| «Недостаточно прав» | Нажми «Перезапустить от администратора» и сам подтверди запрос Windows, либо используй библиотеку с доступом на запись. |
| Скачивание UE4SS не удалось | Проверь сеть; можно отдельно скачать точный архив build 1028 и выбрать ZIP. Частично скачанный файл не устанавливается. |
| «Unexpected … checksum» | Выбран другой/изменённый архив. Сверь версии и SHA-256 в INSTALL.md. |
| Рюкзак пуст / ошибка чтения | Персонаж должен быть загружен. Нажми «Обновить», дождись результата, не скрывая вкладку. После загрузки другого сохранения сделай новый снимок. |
| Открытая карта не даёт целей | Оставь карту КПК открытой до завершения чтения; после её закрытия живые маркеры могут быть очищены. |
| У цели неизвестная высота | Область может быть не загружена. Без проверенной Z прыжок отключён; не подставляй случайную высоту. |
| Существо не появилось внутри здания | Попробуй открытое место и меньшую дистанцию. Точная причина отказов внутри базы не установлена. |
| В карточках нет полного описания | Оно не распространяется вместе с игрой; выполни необязательный локальный импорт из INSTALL.md. |
| Windows блокирует EXE/DLL | Пакет не имеет коммерческой подписи. Проверь источник/хеш и при необходимости собери из исходников; проект не требует отключать защиту Windows. |
| Появилась просадка FPS | Сравни одинаковое место/ракурс/настройки со скрытым меню и фокусом в игре. Созданные NPC, подгрузка мира и сам UE4SS могут влиять на результат. |

## Отчёт об ошибке

Укажи Steam build, версию UE4SS/фикса, шаги воспроизведения и затронутый ID. Для FPS нужны одинаковые условия замера. Прикладывая фрагмент `UE4SS.log` или снимок окна, предварительно убери личные пути и другие данные, которые не хочешь публиковать. Сохранения и полные архивы игры не нужны.
