# Использование

## Запуск и клавиши

Запускай игру через Steam как обычно. Меню запускается скрытым и автоматически закрывается вместе с игрой. Это отдельное окно Windows; удобнее играть в режиме без рамки.

| Действие | Клавиша |
| --- | --- |
| Открыть / скрыть меню | **Ctrl + Alt + S** |
| Перейти к поиску текущей вкладки | **Ctrl + F** |
| Скрыть окно меню | **Esc** |

Крестик скрывает окно в трей. Полный выход — значок Zone Spawner → «Завершить». После такого выхода во время игры запусти `ZoneSpawner.exe` вручную или дождись следующего запуска игры.

## Каталог

Выбери категорию, введи русское/английское название, ID или несколько слов, затем количество **1–999** и «Выдать в инвентарь». Создание доступно при загруженном персонаже. «Команда выдана игре» означает отправку команды: результат проверяй в инвентаре. Автоматического повторения нет.

Избранное сохраняется в `favorites.txt`. Квестовые, служебные ID и чертежи скрыты по умолчанию. Их включение не означает, что каждый прототип безопасен или поддерживает обычную выдачу.

### Артефакты

Редкость и её сортировка видны только в категории «Артефакты»: обычная, необычная, редкая, легендарная. В остальных категориях этот фильтр отсутствует.

В карточке «Свойства» показаны базовые эффекты, уровни и полезное/вредное действие. Для особых артефактов указаны ограничения; условная Blueprint-механика не измеряется в реальном времени. Импортированное игровое описание доступно в соседней вкладке.

### Калибры и совместимость

У оружия и патронов есть «Калибр» и сортировка по нему. Поиск понимает, например, `5.45x39` и `5.45×39`. Уникальные варианты имеют собственные параметры: «Крысобой» — 9x18, «Зубр» — 9x19.

У патронов и обвесов видна колонка «Совместимое оружие». Наведи указатель для полного списка или открой карточку «Совместимость». Поиск по названию/ID ствола находит подходящие патроны и обвесы. Для патронов учтены калибр и тип пули; список относится к базовым настройкам. Переоборудование оружия у техника может изменить совместимость.

ВОГ-25, HEDP, ПГ-7В и батареи гаусс-пушки находятся в «Патронах». Для трёх 7.62x39 список не подтверждён текущими данными; отсутствие списка не означает запрет использования.

## Рюкзак

Загрузи сохранение и открой вкладку «Рюкзак». Меню прочитает реальные количества известных ID за несколько секунд. Выбери предмет, количество и **«Добавить такие же»**. Для выбранных патронов доступны **+30 / +60 / +100**: тип пули и ID сохраняются.

Это создание нового предмета того же прототипа. Износ, улучшения и индивидуальное состояние оружия не копируются. Неизвестные каталогу и служебные/квестовые предметы нельзя дублировать из этой вкладки.

После торговли или использования предметов нажми «Обновить». Снимок не обновляется непрерывно и не является атомарным. Скрытие меню/переход на другую вкладку отменяет незавершённое чтение; после выдачи выполняется одно обновление. Новые ID других модов могут отсутствовать.

## Телепорт

Нажми **«Моя позиция»**, чтобы прочитать текущие XYZ. Введи название и сохрани свою точку. Выбор точки подставляет координаты; «Телепорт по координатам» отправляет прыжок. **«Вернуться перед прыжком»** хранит исходную позицию последнего отправленного прыжка текущей игровой сессии. Свои точки сохраняются в `teleport-points.json`.

Координаты игры в сантиметрах. Перед проверкой новых точек сделай сохранение; неизвестная высота может привести к падению или попаданию в геометрию.

### Цели заданий

1. Открой **карту КПК** в игре и оставь её открытой.
2. В меню выбери **«Телепорт → Цели заданий → Обновить цели»**.
3. По умолчанию отображаются отслеживаемые цели. Флажок показывает прочие видимые метки заданий; они могут включать выдающих задания персонажей.
4. Выбери цель и проверь высоту. Если указано **«Не загружена»**, телепорт заблокирован до явного ввода Z. Изменение только X/Y запрет не снимает.

Названия заданий пока недоступны, поэтому используются тип и номер метки. Число активных заданий и число меток не обязаны совпадать. Высота определяется по загруженной поверхности: внутри здания это может быть крыша или другой этаж. После закрытия карты для нового чтения потребуется открыть её снова.

## Персонажи и мутанты

Выбери категорию, прототип, количество **1–5** и расстояние **5–100 метров** перед игроком. Для NPC доступен ранг **1–4**; у мутантов ранг отключён. Выбирай свободное место: внутри здания спаун может не сработать.

Создание существ нагружает ИИ. Сюжетные/служебные варианты скрыты; копия сюжетного NPC не возвращает исходный UID и квестовые связи. Команда использует `bDestroyOnOffline=true`, но удаление всех видов при уходе в офлайн отдельно не подтверждено.

## Журнал

Показывает последние 100 действий текущего сеанса меню. Журнал не сохраняется в публичный репозиторий и не отправляется по сети. Принятая команда сама по себе не подтверждает результат в мире.
