# Локации и возможности техников

`locations.json` содержит только фактические имена, координаты и связи улучшений с собственными пояснениями. Сырьё игры, текст диалогов, карты и изображения не распространяются. `locations-info.json` фиксирует хеши источников для Steam build 25382007.

## Координаты

12 точек получены из `FastTravelLocationPrototypes.cfg.bin → PlayerLocation`: Залесье, Террикон, Укрытие, Султанск, Деревня новичков, Цементный завод, Росток, Янов, Малахит, Химзавод, Припять и «Сказочный».

Это штатные позиции игрока после путешествия с проводником, а не места NPC, центры маркеров карты или высоты, взятые наугад. В Икаре, на Шевченко и в НИИЧАЗ готовой позиции этого типа не найдено: кнопка прыжка из справочника отключена. Свои точки продолжают работать отдельно.

Каждый готовый прыжок пока не проверен индивидуально в запущенной игре. Исходные координаты и возврат проверены в тестах меню. Каталог не проверяет открытие базы, сюжет, репутацию или загруженность уровня; он не меняет задания и не открывает сервисы.

## Специализации

Для каждой модели пересекаются `UpgradePrototypeSIDs` из `ItemPrototypes` (броня/шлемы) или `WeaponGeneralSetupPrototypes` (оружие) со списком `NPCPrototypes.Upgrades`, у которого `Enabled=true`.

Числитель — размер пересечения, знаменатель — весь набор этой модели. Сюда входит установка обвесов. Это набор возможностей, а не число одновременно устанавливаемых модификаций: требования чертежей, предыдущих улучшений, взаимоисключающие ветки, сюжетные переменные и репутация отдельно не моделируются. Фильтр предмета показывает техников с непустым пересечением, включая частичную поддержку.

Общий сюжетный `FaustPsyResist_Quest_1_1` исключён из обоих чисел: один такой апгрейд не означает специализацию техника на всех экзоскелетах. Начальный и поздний профили Банзая разделены. Для Штепселя отмечен сюжетный переезд в Росток; для лабораторного техника без списка upgrades не заявлены неподтверждённые улучшения. Имена используются из русской локализации текущей игры: Кондёр, Шуруп, Гарпия, Медляк и другие.

Сетевые справочники использовались для сверки географии: [официальная справка о техниках и чертежах](https://support.stalker2.com/hc/en-us/articles/27929396562065-NPC-Interactions), [карта с извлечёнными данными и сведениями механиков](https://github.com/thexii/stalker-map). Старые руководства могут использовать другие локализованные имена и не учитывать новые сюжетные профили. Координаты и численные возможности взяты из локальной игры, а не скопированы из сетевых карт.

## Обновление данных

Разработческий инструмент `tools/build_locations.py` требует Python 3.11+, официальный repak и свою установленную поддерживаемую игру. Он проверяет хеш EXE, извлекает необходимые CFG и локализацию во временную папку и пишет только компактный фактологический каталог:

```powershell
python ./tools/build_locations.py `
  --game-root 'D:\SteamLibrary\steamapps\common\S.T.A.L.K.E.R. 2 Heart of Chornobyl' `
  --repak 'D:\Tools\repak\repak.exe'
```

Проверки WinForms охватывают регион/поиск/модель, профили Банзая, запрет отсутствующей точки, неизменные координаты запроса, возврат, изоляцию личных точек/целей заданий и простой без новых запросов миру. Lua-мост для этой функции не изменялся.
