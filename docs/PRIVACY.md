# Privacy notice

Zone Spawner is a local Windows companion and mod for the single-player game S.T.A.L.K.E.R. 2.

## During gameplay

The menu communicates with its UE4SS Lua mod through local files in the bridge directory. The program does not implement telemetry, analytics, advertising or upload of saves, inventory contents, quest markers or teleport positions. Favorites, saved positions and installation information are stored locally.

This notice covers our own code. It does not describe all network behavior of the game, Steam, Windows or external mod loaders.

## Setup and optional tools

At the user's request, the setup wizard downloads a pinned UE4SS archive from the upstream GitHub release. The Nexus button opens the compatibility-fix author's page in the user's web browser. The game-launch button opens a local Steam URI.

These requested connections are handled by the corresponding service and browser. Sign-in credentials for Nexus, GitHub or Steam are not requested by Zone Spawner. The installer does not upload the local installation manifest or game files.

The optional description-import tool reads the user's local game files and uses a separately obtained repak executable. It does not upload the extracted descriptions.

## Development and support

GitHub hosts public source code and build artifacts. If the project is accepted for SignPath Foundation signing, the signing service will receive the maintainer's account/application information and our release binaries with public build-origin metadata; players do not need a SignPath account. No such signing integration is active yet.

Bug reports are optional and public when submitted to GitHub Issues. Please remove personal paths, account details or other private information from screenshots and logs before posting them.

Service-specific handling is described by the respective providers:

- [GitHub privacy statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)
- [Nexus Mods privacy policy](https://help.nexusmods.com/article/20-privacy-policy)
- [SignPath privacy policy](https://signpath.io/privacy-policy)
